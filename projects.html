projects

Things I've built for fun, mostly to understand how they work.

Systems and ML

  • chibillm: Zero-dependency C++ LLM inference engine with custom Metal kernels. It runs Qwen3.5, and I'm working on getting Qwen3.8-27B to run efficiently.
  • kestrel: Hybrid search engine in Rust that combines BM25 and vector search with reciprocal rank fusion. Embeds document chunks locally and can snapshot and restore collections.
  • haystack: Distributed file system in Go, inspired by Facebook's Haystack. A Raft-based directory cluster maps files to append-only volumes and coordinates replication across store servers.

Cryptography

  • newspeak: End-to-end encrypted chat in Rust implementing Signal's Post-Quantum Extended Diffie-Hellman and Double Ratchet, with a gRPC server and a terminal UI.
  • c25519: Side-channel-resistant Ed25519 and SHA-512 in C, tuned for practical performance and tested against a broad set of test vectors.

Languages

  • ff: Single-file C compiler that can compile itself to ARM64.
  • kukka: Small, fast parser combinator library in Rust that uses static dispatch instead of trait objects. JSON and CSV parsers take a few lines.

Smaller and older experiments are on GitHub.
